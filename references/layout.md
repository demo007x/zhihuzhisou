# 答案页版式规范（layout）

> 定义「知乎智搜」HTML 答案页的固定板块：几块、放什么、怎么呈现。
> 原则：固定版式，AI 只负责填充内容，不发明新板块、不改结构。

---

## 一、板块总览（固定 5 块，顺序不可变）

```
页眉 · 意图锚点     ← 你问的是什么 + 拆成了哪几问
板块1 · 先说结论     ← 人话结论 + 适用条件 + 反转信号
板块2 · 大家怎么说   ← 按子问题分组的素材 + 可信度标 + 来源锚点（标题随形态变）
板块3 · 有争议的地方 ← 正反并置 + 分歧点（无冲突时降级为「注意事项」）
板块4 · 出处         ← 全部真实链接清单（轻量页脚）
```

> 板块标题**不写死**，由答案数据里的 `titles` 字段控制：对比类→「怎么选」，教程类→「怎么做」，观点类→「大家怎么说」，来源→「出处」。默认词见 answer-schema。

---

## 二、各板块定义

### 页眉 · 意图锚点
- **放什么**：原样呈现「用户原始问题」+ 系统拆出的「子问题标签」。
- **呈现**：顶部一块，`你问的是：<原始问题>` + 子问题标签列表。
- **目的**：让用户一眼确认「AI 理解对了吗」，错了可指出（解决"专有名词被拆错"的痛点）。

### 板块1 · 结论区（顶部，人话）
- **放什么**：一句人话版直接结论 + 适用条件（分人/分场景）+ 反转信号。
- **呈现**：
  - 醒目「一句话结论」卡，口语化、有立场，不机器腔；
  - 下方小字：适合谁 / 不适合谁；当 XX 时结论失效。
- **目的**：先给答案，解决"太官方、读不下去"。

### 板块2 · 大家怎么说（主体，标题随形态变）
- **放什么**：top20~30 素材，按「子问题」分组，每条挂来源锚点 + 可信度标。
- **标题**：由数据 `titles.evidence` 决定——对比类「怎么选」、教程类「怎么做」、观点类「大家怎么说」、事实类「事实」。
- **呈现**：对比表（含「来源」「可信度」列）或步骤/列表，每条挂来源锚点 + 可信度标（纯 CSS 圆点，不用 emoji）。
- **目的**：解决"不知道准不准"——每条一眼可见可信度 + 可点回原文。

### 板块3 · 有争议的地方（有冲突才显示）
- **放什么**：正面 vs 反面观点强制并置 + 分歧点说明。
- **呈现**：左右/上下两栏对照（正方 vs 反方）+ 一句「分歧点在哪、在什么条件下各自成立」。
- **降级**：若该问题无明显正反对立（如纯教程），本板块改为「注意事项」（列出坑/边界）。
- **目的**：解决"AI 漏掉反面意见"。

### 板块4 · 出处（底部，轻量）
- **放什么**：本次答案用到的全部真实来源，集中可点。
- **呈现**：链接清单：标题 + 作者 + 来源平台（知乎/全网），点击跳原文。
- **目的**：想深挖时一键直达，而非被迫逐个找。

---

## 三、呈现风格基调（风格细节后续定，此处只立基调）

- 结论区是"人话"、有立场；证据/来源区是"客观"、可溯源。
- 可信度用颜色区分，且**始终可见**，不折叠、不隐藏。
- 软文"降权但不删除"，标角标而非剔除。
